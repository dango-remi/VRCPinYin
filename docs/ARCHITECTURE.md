## 1. 项目概述

### 1.1 背景

在使用 Meta Quest Pro 通过串流（Virtual Desktop / Oculus Link / Steam Link）玩 VRChat 时，头显自带的键盘**不支持中文输入法**，导致在 VR 中无法输入中文。

这是一个严重的问题：
- 中国用户无法在 VRChat 中用中文交流
- 搜索中文内容（世界名、用户名）困难
- 影响用户体验和社交体验

### 1.2 目标用户

| 用户群体 | 使用场景 |
|----------|----------|
| Quest Pro 串流用户 | 主要目标用户，无法使用中文输入 |
| 其他 VR 头显用户 | 如果头显键盘不支持中文，也可使用 |
| PC VR 用户 | 可选使用，提供更好的中文输入体验 |

### 1.3 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 拼音输入 | 通过虚拟键盘输入拼音 | P0 |
| 候选词选择 | 显示候选词列表，支持选择 | P0 |
| 聊天框发送 | 通过 OSC 直接发送到 VRChat 聊天框 | P0 |
| 剪贴板输出 | 通过剪贴板输出到任意输入框 | P1 |
| 快捷键唤起 | 手柄快捷键显示/隐藏 Overlay | P1 |
| 常用词记忆 | 记忆常用词组，提高输入效率 | P2 |
| 键盘布局自定义 | 支持自定义键盘布局 | P2 |
| 多输入法支持 | 支持五笔等其他输入法 | P3 |

### 1.4 非目标

- 不支持 VRChat 原生键盘的替换（技术上无法实现）
- 不支持语音输入（超出项目范围）
- 不支持手写输入（超出项目范围）

### 3.3 各模块详细说明

#### 模块 1：通信协议（基础层）

**职责**：
- 定义 WebSocket 消息的 JSON 格式
- 定义事件类型（按键、候选词选择、确认等）
- 定义状态机（输入状态：空闲/输入中/选词中）
- 定义错误码和错误处理规范

**输出**：
- `docs/PROTOCOL.md` - 详细的协议文档

**被依赖**：
- 所有其他模块都依赖此模块定义的消息格式

---

#### 模块 2：WebSocket 服务（PC 端）

**职责**：
- 启动 WebSocket 服务器，监听端口 8765
- 管理 Overlay 连接（支持单连接）
- 消息路由：将收到的消息分发给输入法引擎
- 心跳检测：定期发送 ping，检测连接状态
- 重连处理：处理 Overlay 断开后的重连

**技术选型**：
- C# WebSocketSharp 或 Fleck

**输出**：
- `Server/VRCPinYinServer/WebSocket/` 目录

---

#### 模块 3：输入法引擎（PC 端）

**职责**：
- 与 Windows IME API / TSF 交互
- 拼音解析：将按键序列转换为拼音
- 候选词查询：根据拼音查询候选词
- 词组组合：支持多字词组输入
- 常用词记忆：记录用户常用词，提高排序

**技术选型**：
- Windows TSF (Text Services Framework)
- 或使用第三方拼音库（如 pinin4net）

**输出**：
- `Server/VRCPinYinServer/IME/` 目录

---

#### 模块 4：文字输出（PC 端）

**职责**：
- **模式 1 (OSC 输出)**：
  - 通过 OSC 协议发送 `/chatbox/input` 到 VRChat
  - VRChat 端口：9000
  - 直接发送到聊天框
- **模式 2 (剪贴板输出)**：
  - 复制文字到剪贴板
  - 模拟 Ctrl+V 粘贴
  - 适用于任意输入框
- **模式 3 (SendInput)**（备选）：
  - 模拟键盘逐字输入
  - 用于不支持粘贴的场景

**技术选型**：
- OSC：OscCore 库
- 剪贴板：Windows Clipboard API
- SendInput：user32.dll SendInput

**输出**：
- `Server/VRCPinYinServer/Output/` 目录

---

#### 模块 5：Overlay 框架（VR 端）

**职责**：
- 初始化 SteamVR Overlay
- 管理 Overlay 的显示/隐藏
- 处理手柄快捷键唤起
- 管理 Overlay 的位置和朝向（跟随头部或固定位置）
- 处理 Overlay 的渲染设置（分辨率、帧率）

**技术选型**：
- Unity 2022.3 LTS
- SteamVR Unity Plugin

**输出**：
- `Overlay/Assets/Scripts/Overlay/` 目录

---

#### 模块 6：虚拟键盘 UI（VR 端）

**职责**：
- 设计键盘布局（QWERTY 或其他）
- 实现按键的 VR 交互（射线点击）
- 处理按键事件（字母、数字、符号、功能键）
- 视觉反馈（按下效果、悬停效果）
- 支持特殊按键（退格、空格、回车）

**技术选型**：
- Unity UI (Canvas)
- SteamVR Laser Pointer

**输出**：
- `Overlay/Assets/Scripts/Keyboard/` 目录

---

#### 模块 7：候选词面板（VR 端）

**职责**：
- 显示候选词列表（从 PC 端接收）
- 处理候选词选择（数字键或点击）
- 支持翻页（上一页/下一页）
- 高亮当前选中的候选词
- 显示当前输入的拼音

**技术选型**：
- Unity UI (Canvas)
- 动态生成候选词按钮

**输出**：
- `Overlay/Assets/Scripts/Candidates/` 目录

---

#### 模块 8：通信客户端（VR 端）

**职责**：
- 建立 WebSocket 连接到 PC 端
- 发送按键事件到 PC 端
- 接收候选词列表
- 处理连接断开和重连
- 处理消息序列化/反序列化

**技术选型**：
- WebSocketSharp 或 Best HTTP

**输出**：
- `Overlay/Assets/Scripts/Network/` 目录

## 4. 核心设计决策

### 4.1 为什么选择 SteamVR Overlay 而不是 VRChat 内置方案？

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| VRChat 内置 Udon 键盘 | 原生集成，无需额外软件 | 只能在支持的世界使用，需要世界开发者配合 | ❌ 不适合 |
| SteamVR Overlay | 全局可用，不依赖 VRChat 世界 | 需要额外的 Unity 程序 | ✅ 选择此方案 |
| 独立 VR 应用 | 完全控制 | 无法叠加在 VRChat 上 | ❌ 不适合 |

**决策**：使用 SteamVR Overlay，因为它可以全局叠加在 VRChat 之上，不依赖特定世界。

---

### 4.2 为什么选择 WebSocket 而不是直接在 VR 端处理输入法？

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| VR 端直接处理 | 架构简单 | Unity 中没有成熟的中文输入法库；词库管理复杂 | ❌ 不适合 |
| WebSocket + PC 端处理 | 可以利用 Windows 成熟的 IME；词库丰富 | 需要额外的 PC 端服务 | ✅ 选择此方案 |

**决策**：使用 WebSocket 通信，将输入法处理放在 PC 端，利用 Windows 成熟的 IME API。

---

### 4.3 为什么选择双模式输出（OSC + 剪贴板）？

| 场景 | OSC `/chatbox/input` | 剪贴板 + Ctrl+V | SendInput |
|------|---------------------|-----------------|-----------|
| VRChat 聊天框 | ✅ 完美支持 | ⚠️ 可用但需要焦点 | ⚠️ 慢 |
| VRChat 搜索框 | ❌ 不支持 | ✅ 可用 | ⚠️ 慢 |
| Udon UI 输入框 | ❌ 不支持 | ✅ 可用 | ⚠️ 慢 |
| 其他游戏/应用 | ❌ 不支持 | ✅ 可用 | ✅ 可用 |

**决策**：
- **模式 1 (默认)**：使用 OSC `/chatbox/input`，专门用于 VRChat 聊天框
- **模式 2 (备选)**：使用剪贴板 + Ctrl+V，用于其他输入框
- 用户可以在 Overlay 中切换模式

**理由**：
- OSC 模式不需要 VRChat 窗口焦点，体验更好
- 剪贴板模式通用性强，覆盖 OSC 不支持的场景
- 两种模式互补，提供完整的解决方案

---

### 4.4 为什么选择 WebSocket 端口 8765？

**决策**：使用 `ws://127.0.0.1:8765` 作为 WebSocket 端口

**理由**：
- 8765 是一个非常见端口，不太会与其他服务冲突
- 使用 127.0.0.1 限制只能本地连接，安全性更高
- 不需要管理员权限

**备选方案**：
- 如果 8765 被占用，可以在配置文件中修改端口

### 4.5 为什么 VR 端使用 Unity 而不是其他引擎？

| 引擎 | SteamVR 支持 | UI 开发 | C# WebSocket 库 | 结论 |
|------|-------------|---------|-----------------|------|
| Unity | ✅ 官方插件 | ✅ 成熟 | ✅ 多个选择 | ✅ 选择此方案 |
| Unreal | ✅ 官方插件 | ⚠️ UMG 较复杂 | ⚠️ 选择较少 | ❌ 不适合 |
| Godot | ⚠️ 社区支持 | ✅ 不熟 | ⚠️ 选择较少 | ❌ 不适合 |

**决策**：使用 Unity 2022.3 LTS

**理由**：
- SteamVR Unity Plugin 是官方支持的
- Unity UI (Canvas) 开发简单
- 有多个成熟的 WebSocket 库可选

## 6. 数据流详解

### 6.1 用户输入流程

```
1. 用户按下快捷键 → Overlay 显示
   │
   ▼
2. 用户点击虚拟键盘 'n' 键
   │
   ▼
3. VR 端发送消息到 PC 端：
   {
     "type": "key_press",
     "data": {
       "key": "n",
       "timestamp": 1234567890
     }
   }
   │
   ▼
4. PC 端输入法引擎处理：
   - 当前拼音："" → "n"
   - 查询候选词：["n", "你", "那", "呢", ...]
   │
   ▼
5. PC 端发送候选词到 VR 端：
   {
     "type": "candidates",
     "data": {
       "pinyin": "n",
       "candidates": ["n", "你", "那", "呢", "年", "能"],
       "page": 1,
       "totalPages": 10
     }
   }
   │
   ▼
6. VR 端显示候选词面板
   │
   ▼
7. 用户继续输入 'i'
   │
   ▼
8. 重复步骤 3-6，候选词更新为 ["ni", "你", "尼", "妮", ...]
   │
   ▼
9. 用户点击候选词 "你"
   │
   ▼
10. VR 端发送消息到 PC 端：
    {
      "type": "select_candidate",
      "data": {
        "index": 1,
        "text": "你"
      }
    }
    │
    ▼
11. PC 端处理：
    - 将 "你" 加入待发送文本
    - 清空当前拼音
    - 发送确认消息
    │
    ▼
12. 用户继续输入，组成句子 "你好"
    │
    ▼
13. 用户点击"发送"按钮
    │
    ▼
14. VR 端发送消息到 PC 端：
    {
      "type": "send_text",
      "data": {
        "text": "你好",
        "mode": "osc"  // 或 "clipboard"
      }
    }
    │
    ▼
15. PC 端根据 mode 输出文字：
    - mode = "osc"：发送 OSC `/chatbox/input "你好" true`
    - mode = "clipboard"：复制到剪贴板 + 模拟 Ctrl+V
    │
    ▼
16. 文字出现在 VRChat 中
```

### 6.2 状态机

```
                    ┌─────────────┐
                    │    空闲     │
                    │  (Idle)     │
                    └──────┬──────┘
                           │ 用户按键
                           ▼
                    ┌─────────────┐
         ┌─────────▶│  输入中     │◀─────────┐
         │          │ (Typing)    │          │
         │          └──────┬──────┘          │
         │                 │ 选择候选词      │
         │                 │ 或继续按键      │
         │                 ▼                 │
         │          ┌─────────────┐          │
         │          │  已选词     │          │
         │          │ (Selected)  │          │
         │          └──────┬──────┘          │
         │                 │ 继续输入        │
         │                 └─────────────────┘
         │
         │ 发送/取消
         │
         ▼
    ┌─────────────┐
    │    空闲     │
    │  (Idle)     │
    └─────────────┘
```
