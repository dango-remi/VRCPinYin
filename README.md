# VRCPinYin

一个为 VRChat 设计的 SteamVR Overlay 中文输入法工具。

## 背景

在使用 Meta Quest Pro 通过串流（Virtual Desktop / Oculus Link / Steam Link）玩 VRChat 时，头显自带的键盘不支持中文输入法，导致在 VR 中无法输入中文。

VRCPinYin 通过在 PC 端处理输入法，并将界面以 SteamVR Overlay 的形式叠加在 VRChat 之上，解决了这个问题。

## 工作流程

1. **唤起**：用户在 VR 中按下快捷键，VRCPinYin Overlay 浮现在视野中
2. **输入**：用户使用控制器点击虚拟键盘上的拼音字母
3. **处理**：按键通过 WebSocket 发送到 PC 端，PC 端调用系统输入法引擎
4. **展示**：PC 端返回候选词列表，Overlay 展示候选词
5. **选择**：用户点击选择候选词
6. **输出**：PC 端将选中的文字输入到当前焦点窗口（VRChat）

## 技术栈

### VR 端 (Overlay)
- **引擎**：Unity 2022.3 LTS
- **VR 框架**：SteamVR Unity Plugin
- **界面**：Unity UI (Canvas)
- **通信**：WebSocket (WebSocketSharp 或 Best HTTP)

### PC 端 (Windows 服务)
- **语言**：C# (.NET 6/7) 或 C++
- **输入法交互**：Windows IME API / TSF (Text Services Framework)
- **通信**：WebSocket 服务器
- **文字输出**：
  - 方案 A：复制到剪贴板，模拟 Ctrl+V
  - 方案 B：模拟键盘输入（SendInput）
  - 方案 C：直接注入到目标进程
